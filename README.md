# 会话归档 / Session Archive

pi-web-ui 社区插件。左栏每个会话行多一个 🗄 图标：点一下把对话从侧边栏收起来（**不删文件**），并选一个到期时间；到期后插件才删掉对应的会话 `.jsonl`。

- 插件 ID：`session-archive`，API v2，MIT。
- 不调用模型、不修改原生会话内容、不接管聊天。

## 为什么需要 DOM 权限

宿主的 slot 框架里，`leftpanel.sessions` 的会话行条目**拿不到这一行的 target**（只有 `leftpanel.project` 有），所以插件无法从声明式条目知道"用户点的是哪一行"。要在行内加真按钮、并且立刻隐藏归档的行，只能走 `permissions: ["dom"]` 的 DOM 注入：装好后在 **设置 → 插件** 里对本插件点一次「授权 DOM 访问」（服务端记在 `<dataDir>/plugin-dom.json`，未授权时 bundle 直接 403）。

## 用法

1. 左栏会话行 hover → 出现 ✏（重命名）/ 🗄（归档）/ 🗑（删除）三个按钮，点 🗄。
2. 弹窗选保留期：1 天 / 7 天 / 30 天 / 永不删除（默认取设置里的「默认保留天数」，默认 7）。
3. 确认后该行立刻从侧边栏消失；文件仍在 `~/.pi/agent/sessions/...` 里，只是宿主看不到它了。
4. 管理入口：左栏「项目」标题栏右侧的 🗄 图标（新版 UI），或「历史对话」标题栏的 🗄（旧版 UI）；点击打开**归档管理面板**：hover 条目在标题右侧出现 ↺（恢复，行滚到视口并闪烁定位）与 🗑（立即删除文件，二次确认）。要改到期天数：改设置里的默认天数后重新归档，或直接调 `POST /retention`。
5. 归档成功后的 toast 上有「撤销」。

到期后的行为（默认**不删文件**）：服务端每 10 分钟扫一次（启动后 8 秒还会补一次），到期的记录只被标记成 `expired` —— 行继续隐藏、文件原地不动、**不弹任何授权框**。真删只有两条路：

- 面板里点「删除文件」→ 才向该会话目录申请一次访问授权，同意后删；
- 或设置里打开「到期自动删除会话文件」→ 但只在**已经授权过**的目录里才删，绝不为了删去弹框；没授权就退回只标记。

删除前硬校验路径必须落在会话根目录内且是 `.jsonl`；否则只记错误、不动文件。恢复/删除后的记录保留 30 天再清出状态文件。

**归档本身从不申请目录授权、从不写任何文件** —— 只写一条插件状态记录 + 浏览器隐藏那一行。

## 数据与授权

- 归档状态：`<dataDir>/session-archive/state.json`（原子写、`0600`）。不动原生会话。
- 会话目录授权：第一次归档时向会话文件所在目录申请访问（`fs.requestAccess`），记在宿主的目录授权表里；拒绝授权也能归档和隐藏，只是到期删不掉（面板里会显示原因）。
- 会话根目录判定：`PI_CODING_AGENT_SESSION_DIR`，否则 `(PI_CODING_AGENT_DIR 或 ~/.pi/agent)/sessions`。与宿主、md-chat 的布局一致。

## 设置项

| key | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `defaultDays` | number | 7 | 归档弹窗预选的天数；0 = 预选"永不删除" |
| `showActiveRowButton` | boolean | false | 当前打开的对话是否也显示归档按钮 |
| `autoDeleteOnExpiry` | boolean | false | 到期自动删文件（仅对已授权目录生效，不弹框） |

## 安装 / 开发

```sh
# 从本地目录装（开发调试）
pi-web-ui install /path/to/Mkmo --name session-archive

# 从 GitHub 装
pi-web-ui install <owner>/<repo> --name session-archive
```

更新插件后要**重启 pi-web-ui**（服务端模块有缓存），再刷新浏览器。装好后重启/刷新，然后：

```sh
npm i -D jsdom --ignore-scripts   # 只有 client.dom.test.mjs 需要它
node --test "test/*.test.mjs"     # 40 个用例
```

## 已知边界

- 隐藏的是**侧边栏行**：归档后该对话不再出现在左栏，点不进去；但对话主视图里如果它正开着，仍可继续读（新开对话即离开）。归档后没有"只读打开"入口——要从侧边栏读回，先恢复。
- 宿主完全刷新侧边栏（切项目、重连）后行会重新渲染，插件靠 MutationObserver + 1.5s 兜底重扫重新隐藏，不需要手动操作。隐藏同时按 `title` 里的 `.jsonl` 路径和宿主 `data-session-key`（归一化路径或会话 id）匹配，所以「另一处 / 运行的对话」这类没有 `.jsonl` title 的行也能藏住。
- 宿主自带的 🗑（`deleteSession`）是**真删物理文件、不可恢复**：它会校验必须在会话目录内、处理运行中/被占用的会话、别处开着就中止，然后 `rmSync` 掉 jsonl 并清 pinned/草稿/缓存。本插件的「归档」和它完全不是一条路。
- 原生会话文件被外部删除（例如宿主自己的删除按钮）时，归档记录仍在；到期的删除会识别"文件已不在"并直接收尾。
- 插件被卸载后状态文件留在 `<dataDir>/session-archive/`，行不再隐藏、也再无自动删除。
